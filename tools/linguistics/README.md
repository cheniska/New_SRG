> **Актуальное направление (21.11.2026):** для ндзераков прежде всего отбираем звучание личных имён, этнонима, планет, звёзд, секторов, классов кораблей, ругательств и идиом. ## Подтверждённые ориентиры

- **Грондары**: существующее название сохраняется; гортанный рычащий язык.
- **Ндзераки**: грузинский — сложные группы нескольких согласных подряд; название «ндзераки» пока рабочее.
- **Ксеноподы**: арабский — в досье подтверждён как ориентир звучания имён.
- **Этериане**: японский — ориентир открытых слогов имён, поверх которого есть собственные тоны.

Остальные опорные языки предстоит согласовать. Опорный язык задаёт звучание и исходные корни, **не** предполагает копирования грамматики или культуры.

## Цель

Слова должны восприниматься как принадлежащие самостоятельным инопланетным языкам, а не как слегка изменённые реальные имена. При этом каждое слово имеет прослеживаемую этимологию и устойчивые правила трансформации.

## Конвейер

1. Выбрать **реальное исходное слово**, его язык, написание, значение и, по возможности, фонемную запись.
2. Разбить на слоги по правилам опорного языка; при неоднозначности сохранить выбранные границы.
3. Применить **инверсию порядка слогов** (полную либо заданную профилем), не переворачивая порядок букв внутри слогов.
4. Применить **регулярные фонетические замены**, согласованные для цивилизации, а не случайные посимвольные подстановки.
5. При необходимости изменить структуру слога (сокращение гласных, слияние соседних согласных, перестановка групп), не нарушая фонологию выбранного профиля.
6. Добавить особые знаки **только при наличии значения**: апостроф для гортанной смычки / определённого звука, дефис для морфемной границы, специальные символы для уникальных фонем. Знак не обязан встречаться в каждом слове.
7. Записать результат на Лингве / кириллицей для игрового интерфейса, сохранив фонемную форму.
8. Сохранить исходное слово, разбиение и журнал преобразований для **точной обратной реконструкции**.

**Обратный режим:** по слову из словаря — восстановление исходника через сохранённый журнал; для неизвестного слова — список возможных реконструкций с пометкой неоднозначности. Замены, объединяющие разные фонемы, математически не обратимы без метаданных.

## Важные ограничения

- Не заменять буквы апострофами просто для визуальной экзотики: такая запись должна иметь произношение и функцию.
- Не предполагать, что орфографические буквы равны фонемам; грузинский, арабский и японский требуют разных правил обработки.
- Для арабского учитывать огласовки и корневую структуру, для японского — моры и открытые слоги, для грузинского — сложные согласные кластеры.
- Генерация должна быть воспроизводимой, с контролем версии профиля и сохранением этимологии.
- Не выдавать вымышленные корни за реально существующие слова опорного языка.
- Сохранять существующие географические имена и этнонимы до отдельного согласования.

## Предлагаемая структура

- `profiles/` — правила преобразования по расам.
- `lexicons/` — исходные слова, значения, этимология и одобренные результаты.
- `tests/` — примеры и проверки прямого и обратного преобразования.
- `transliterator.py` — будущая реализация движка.

## Ближайший этап

Первый профиль — ндзеракский, на грузинской основе: определить фонемный инвентарь, допустимые группы согласных, схему инверсии слогов и функции апострофа. Затем проверить на реальных словах, а не сразу переименовывать цивилизацию.
