> **Текущая экспериментальная версия 0.3 (`synapt_phrase.py`).** Основа — грузинская лексика с сохранением сложных согласных кластеров. Инверсия слогов отключена. Фонетические изменения: гласные `a→e, e→i, i→a, o→u, u→o`, редкие `sh→zh, ch→ts, gh→kh, v→w, j→zh`. В длинных словах (от восьми латинских символов, минимум три гласные) может отбрасываться только **последняя** гласная. Внутренние гласные не удаляются. В результате не появляются дефисы или декоративные апострофы. Это не полноценная фонология, а воспроизводимый прототип. Согласованные имена `Тнацш/Тнацшк`, `Мцквар`, `Дзгрэт` не пересчитываются. Прежние разделы ниже — история экспериментов, не действующие правила.

> **Обновление 0.2 (текущий движок `synapt_phrase.py`).** Прежние правила полной инверсии слогов, сильного сокращения гласных и повсеместных перестановок согласных признаны неудачными для обычных слов и классов кораблей. Они сохранены ниже только как исторические эксперименты; текущая реализация действует иначе. Для 1–3 условных сегментов порядок сохраняется; для 4+ меняются местами только два последних. Диграфы `sh→zh`, `ch→ts`, `gh→kh`, `v→w` меняются избирательно. Сложные согласные кластеры не разрушаются, удаление слоговых гласных выключено. Никаких автоматических суффиксов и случайных апострофов. Прежние кандидаты имён и названия классов кораблей **не пересчитаны и не утверждены**. Согласованные имена собственные `Тнацш/Тнацшк`, `Мцквар`, `Дзгрэт` не меняются задним числом.

# Синаптский профиль v0.1 — экспериментальный

Опорный язык: **грузинский**, прежде всего его способность допускать длинные группы согласных. Ни один вариант этнонима пока не утверждён.

## Основной экспериментальный профиль `synapt_cluster`

Авторский выбор фонетических преобразований с целью подчеркнуть **грузиноподобные скопления согласных** и синаптскую быструю металлическую речь. Это не прямое копирование грузинских фонем и не окончательная лексика расы.

- Одновременные пары латинской фонемной записи: `s ↔ z`, `t ↔ d`, `k ↔ g`, `p ↔ b`.
- Существующие преобразования диграфов `sh → zh`, `ch → ts`, `q → kh`, `v → w` выполняются до перестановок одиночных согласных.
- Длинные группы согласных сохраняются, а не автоматически разбиваются гласными.
- Инверсия слогов включена по умолчанию; апостроф используется лишь для обозначения заданной гортанной смычки.
- Важно: диграфные преобразования пока не всегда взаимно-однозначны; гарантированная реконструкция требует сохранённой записи.

**Прежняя таблица `rotation` — только демонстрация предложенного пользователем принципа, а не утверждённый выбор для синаптов.** `none` отключает перестановки одиночных согласных. При создании новых расовых профилей следует выбирать собственные правила, а не копировать синаптскую таблицу.

## Экспериментальные таблицы перестановок

Добавлен режим `rotation`: одновременные взаимные замены `r ↔ d` и цикл `b → g → t → b`. Для него обратная таблица `d → r`, `r → d`, `g → b`, `t → g`, `b → t`. Все замены применяются **одновременно** к результату инверсии слогов; другие звуки не затрагиваются. Режим `none` сохраняет прежнее поведение. Это пока экспериментальные правила, а не утверждённая фонетика синаптов.

Пример на условной латинской записи: `rdbgt` → `drgtb` (без деления на слоги). Команда: `python transliterator.py encode rdbgt --consonant-map rotation`.

## Алгоритм

1. Ввести реальное слово в латинской транскрипции; значение и оригинальное грузинское написание хранить отдельно в будущем словаре.
2. Предпочтительно указать вручную границы слогов, поскольку автоматическое разбиение согласных кластеров ненадёжно.
3. Инвертировать **порядок слогов**, не порядок букв в них.
4. Применить постоянные экспериментальные изменения: sh→zh, ch→ts, q→kh, v→w.
5. Между слогами перед a/e может появляться апостроф, означающий **гортанную смычку**; в иных местах границы пока обозначаются дефисом. Апостроф не является случайным украшением.
6. Сохранить запись преобразования. Обратное преобразование гарантировано **только по сохранённой записи**; неизвестные слова неоднозначны.

Пример (демонстрационный, не утверждённое синаптское слово): `gamarjoba`, ручное деление `ga-mar-jo-ba` → `ba-jo-mar-ga`. Здесь нет искусственно добавленных апострофов: они должны иметь фонетическую функцию.

**Важное ограничение:** используемая латинская запись пока не является полной фонетической транскрипцией грузинского. Движок — минимальный проверяемый прототип, не полноценная лингвистическая модель. Перед подбором этнонимов необходимо сверить исходные грузинские слова, их значения и реальную слоговую структуру.

## Запуск

```bash
python transliterator.py encode gamarjoba --syllables ga-mar-jo-ba
python -m unittest discover -s tests -v
```

Для обратного преобразования: `python transliterator.py decode '<JSON из encode>'`.
