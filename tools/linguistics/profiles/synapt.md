# Синаптский профиль v0.1 — экспериментальный

Опорный язык: **грузинский**, прежде всего его способность допускать длинные группы согласных. Ни один вариант этнонима пока не утверждён.

## Алгоритм

1. Ввести реальное слово в латинской транскрипции; значение и оригинальное грузинское написание хранить отдельно в будущем словаре.
2. Предпочтительно указать вручную границы слогов, поскольку автоматическое разбиение согласных кластеров ненадёжно.
3. Инвертировать **порядок слогов**, не порядок букв в них.
4. Применить постоянные экспериментальные изменения: sh→zh, ch→ts, q→kh, v→w.
5. Между слогами перед a/e может появляться апостроф, означающий **гортанную смычку**; в иных местах границы пока обозначаются дефисом. Апостроф не является случайным украшением.
6. Сохранить запись преобразования. Обратное преобразование гарантировано **только по сохранённой записи**; неизвестные слова неоднозначны.

Пример (демонстрационный, не утверждённое синаптское слово): `gamarjoba`, ручное деление `ga-mar-jo-ba` → `ba-jo-mar-ga`. Здесь нет искусственно добавленных апострофов: они должны иметь фонетическую функцию.

**Важное ограничение:** используемая латинская запись пока не является полной фонетической транскрипцией грузинского. Движок — минимальный проверяемый прототип, не полноценная лингвистическая модель. Перед подбором этнонимов необходимо сверить исходные грузинские слова, их значения и реальную слоговую структуру.

## Запуск

```bash
python transliterator.py encode gamarjoba --syllables ga-mar-jo-ba
python -m unittest discover -s tests -v
```

Для обратного преобразования: `python transliterator.py decode '<JSON из encode>'`.
