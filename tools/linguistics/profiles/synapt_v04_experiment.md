# Эксперимент 0.4: контекстные звуковые изменения

Новый модуль: [synapt_v04_lab.py](../synapt_v04_lab.py). Предыдущий [synapt_phrase.py](../synapt_phrase.py) не заменён. Оба варианта v0.4 — **лабораторные**, не канон.

## Метод

1. Исходное слово берётся из **проверенной грузинской лексики** и записывается латиницей; автоматический перевод с русского не выполняется.
2. Вариант A: интервокальное `v → w`, интервокальное `g → gh`, начальное `sh → zh`. Другие согласные и группы сохраняются.
3. Вариант Б: правила A плюс `a → e` **только в конце слова после согласной**; в некоторых длинных словах конечное `e` после группы согласных может исчезнуть, если сохраняются минимум два гласных ядра.
4. Результат выдаётся в русской транскрипции с журналом изменений. Обратное восстановление по одному результату не гарантировано; для этого сохраняется исходник.
5. Фонотактическая проверка пока **эвристическая** (проверяет лишь слишком длинные группы согласных), а не полноценный автомат конечных состояний.

## Примеры по правилам

| Исходная латиница | A | Б | Почему |
|---|---|---|---|
| `sava` | `sawa` | `sawe` | v между гласными; затем конечное a |
| `marta` | `marta` | `marte` | конечное a |
| `mtskvar` | `mtskvar` | `mtskvar` | согласный кластер сохраняется |
| `tsnoba` | `tsnoba` | `tsnobe` | конечное a |
| `sheni` | `zheni` | `zheni` | начальное sh |
| `gamarjoba` | `gamarjoba` | `gamarjobe` | конечное a |

**Важно:** это не окончательные синаптские имена и не перевод грузинских слов; таблица демонстрирует работу звуковых законов.

## Проверка качества перед утверждением

- Выбрать 10 проверенных корней имён и 16 проверенных основ классов кораблей.
- Сравнить A/Б по читаемости, фонетическому сходству и уникальности.
- Проверить, не стали ли преобразования слишком слабыми.
- Только после этого формировать продуктивные правила синаптского словообразования и суффиксы технических терминов.
- Не менять согласованные формы **Тнацш/Тнацшк, Мцквар, Дзгрэт**.

## Запуск

```bash
cd tools/linguistics
python synapt_v04_lab.py sava marta mtskvar tsnoba sheni gamarjoba
python -m unittest discover -s tests -p 'test_synapt_v04_lab.py' -v
```
