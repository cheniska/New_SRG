# Морфологический эксперимент 01 — первые семейства слов

**Статус: проектирование с нуля.** Это **не** утверждённая грамматика, не готовый переводчик и не словарь канона. Предыдущие этнонимы, топонимы и суффиксы не используются как образцы. Фонетический ориентир — стрекочущие сочетания мц, цр, кц и другие.

## Задача

Перейти от генерации случайных словоформ к воспроизводимому словообразованию: один корень → несколько связанных по смыслу слов.

## Предварительная модель A: производные суффиксы

| Модель | Суффикс | Назначение | Пример от «дзрим» (обнаруживать) |
|---|---|---|---|
| Основа | Ø | исходное значение | дзрим |
| Деятель | -ик | субъект действия | дзримик |
| Инструмент | -ац | средство / устройство | дзримац |
| Процесс | -э | действие как событие | дзримэ |
| Место | -ор | место действия | дзримор |

Другие семейства:

| Основа и смысл | Деятель | Устройство | Процесс | Место |
|---|---|---|---|---|
| кцэн — мыслить | кцэник | кцэнац | кцэнэ | кцэнор |
| цвэк — сигнализировать | цвэкик | цвэкац | цвэкэ | цвэкор |
| мдзар — сохранять | мдзарик | мдзарац | мдзарэ | мдзарор |
| нцор — перемещаться | нцорик | нцорац | нцорэ | нцорор |

Такая система может создавать функциональные названия классов кораблей, но пока **не означает**, что каждый класс должен буквально называться, например, «инструментом обнаружения».

## Предварительная модель Б: сложение корней

Временный порядок: **определяющий корень + соединительное -и- + главный корень**.

- `цвэкидзрим` — «сигнал + обнаружение», условно связанное с обнаружением сигналов.
- `дзримицвэк` — «обнаружение + сообщение», другой порядок и другое значение.
- `кцэницвэк` — «мысль + сообщение», потенциально интеллектуальная передача данных.

В этой модели сложные формы иногда получаются слишком длинными. Скрипт сообщает об этом, **но не отрезает буквы молча**. Это важнее, чем искусственно делать все технические термины короткими.

## Число и грамматика

Для сравнения с прежним склонением добавлен **новый, не утверждённый аналитический вариант**: частица `зэ` после слова обозначает множественность, например `мцэр зэ`. Он создан независимо от старых решений и пока **не выбран**. Система не вводит пол или грамматический род автоматически.

## Проверка

Модуль [morphology.py](morphology.py) содержит 12 экспериментальных корней и пять категорий (включая исходную форму). Это 60 производных словоформ. Проверено локально: **60 различных форм, 0 коллизий, 0 предупреждений текущей эвристической фонетической проверки**. Шесть модульных тестов прошли.

Ограничения:
- Семантические значения корней назначены для эксперимента, не выведены из реального языка.
- Фонотактический валидатор пока прост: ограничивает максимальную длину и грубые стыки согласных, но **не доказывает физиологическую произносимость**.
- Проверка коллизий относится только к 60 простым производным, не ко всем возможным сложениям и фразам.
- Морфологическая система пока не поддерживает полноценный синтаксис, времена и аспект, личные местоимения или вибрационную маркировку.
- Слова нельзя переносить в основной лор до отбора звучания и значения.

## Запуск

```bash
cd tools/linguistics/reboot
python morphology.py --survey
python morphology.py --root detect --category instrument
python morphology.py --compound signal detect --category instrument
python morphology.py --root person --plural
python -m unittest test_morphology.py -v
```
