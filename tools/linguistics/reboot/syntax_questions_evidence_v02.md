# Синтаксис: вопросы, отрицание, источник — предложения v0.2

**Статус: проектные предложения, не канон.** Проект языка с нуля, прежние имена/этнонимы не служат исходной моделью.

## Уже согласовано

Нейтральный порядок:
**субъект — адресат — прямой объект — время — место — способ — причина — глагол**.
Определения перед существительным. Подлежащее может опускаться только при однозначном контексте. Объект имеет отдельное падежное маркирование, порядок не меняется ради эмоционального выделения.

## Вопрос: предлагаемая система

- Вопрос «да/нет»: конечная самостоятельная частица `цэ?` после глагола, не изменяющая порядок слов.
- Вопрос о конкретном компоненте: вопросительное слово **занимает именно позицию неизвестного компонента**, а в конце остаётся `цэ?`.
- Нельзя задавать вопрос о двух компонентах сразу без повторения вопросительного элемента либо конструкции уточнения.
- Частицы являются пробными: `цэ?` возможно совпадает с приставкой повторительного вида `цэ-` из морфологии. Разделение по границе слова и позиции на письме снимает часть риска, однако желательно проверить по полной грамматике.

## Отрицание: предлагаемая система области действия

- `шэ-` перед глаголом отрицает **событие/утверждение о предикате**.
- Для отрицания отдельной именной группы предлагается отдельная **самостоятельная частица** `шац` непосредственно перед этой группой; она **не** заменяет глагольную приставку.
- Противопоставление «не X, а Y» требует специальной частицы противопоставления и не должно выражаться свободной перестановкой порядка.
- В сложных предложениях отрицание действует только внутри обозначенной границы придаточного.

## Источник информации и степень уверенности

В конце **утвердительного/вопросительного ядра** может находиться отдельный показатель происхождения сведений. Предварительные частицы:

| Основание | Частица (рабочая) | Значение |
|---|---|---|
| Собственное наблюдение | `мцэ` | Говорящий лично воспринял событие |
| Передано другим | `црэн` | Сведения получены извне |
| Выведено из данных | `кцир` | Говорящий заключил по косвенным признакам |
| Не отмечено | Ø | Источник не указан, не означает доказанности |

**Источник ≠ достоверность:** услышанное может быть верным, наблюдение ошибочным. Шкала уверенности и нормы научной речи будут разработаны позже, отдельно от источника.

Порядок элементов в хвосте предложения в версии для обсуждения:
`... ГЛАГОЛ — ЭВИДЕНЦИАЛЬНОСТЬ? — ВОПРОС?`.

Их точные формы и позиции пока не утверждены.

## Минимальные контрасты (русская структурная подстрочная запись)

| Смысл | Структура |
|---|---|
| Исследователь обнаружил сигнал | S — O — V |
| Исследователь **не** обнаружил сигнал | S — O — NEG-V |
| Исследователь обнаружил **не сигнал** | S — NEG-O — V |
| Исследователь обнаружил сигнал? | S — O — V — Q |
| Кто обнаружил сигнал? | WHO(S) — O — V — Q |
| Исследователь обнаружил что? | S — WHAT(O) — V — Q |
| Согласно показаниям другого, сигнал обнаружен | S — O — V — REPORTED |
| По моему наблюдению, сигнал обнаружен | S — O — V — DIRECT |
| Из данных следует, что сигнал обнаружен | S — O — V — INFERRED |

Тестировать различение областей действия даже при опущенных факультативных обстоятельствах. Не выдавать эти формулы за готовую языковую речь.

## Решение на следующем этапе

1. Утвердить / заменить позицию вопросительного показателя.
2. Уточнить сферу отрицания и частицы для отрицания отдельного компонента.
3. Решить, нужны ли источники информации как обязательный грамматический элемент или нормативно обязательны только в некоторых регистрах.
4. Проверить совместное использование вопроса, отрицания и источника информации в 12–20 предложениях.
