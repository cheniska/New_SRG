# Фонотактический генератор — первый проверенный эксперимент

**Дата:** 2026-11-21. **Статус:** лабораторные звуковые формы; это **не** утверждённые имена и **не** слова с заданными значениями. Разработка чистая, без ранее согласованных названий.

Программа: [phonotactics.py](phonotactics.py). Тесты: [test_phonotactics.py](test_phonotactics.py).

## Звуковые правила

- Начальные группы выбираются из явного набора: `мц`, `нц`, `мдз`, `цр`, `дзр`, `кц`, `пц`, `тц`, `цв`, `цш`, `цх`, `чр` и более редкие сложные варианты; встречаются и простые начала.
- Ядро слога: пять гласных или редкие слогообразующие `р`/`н`. Внутренняя запись слогового сонорного отличает его от обычного согласного.
- Ограничены допустимые окончания, запрещены некоторые последовательности аффрикат и слишком длинные межслоговые группы.
- Слова содержат один–три слога, по умолчанию один–два. Отдельный «стрекочущий» стиль чаще использует аффрикаты; «сбалансированный» допускает больше простых начал.
- Длина отображаемого слова сейчас 3–9 кириллических символов. **Это эвристика для первого прототипа**, а не установленная биологическая граница.

## Демонстрационная выборка (seed=42, chitter)

Чрит, Црурк, Гэр, Чрот, Нцав, Раннцэш, Цэнчрат, Пцоцк, Кцва, Оцлу, Пив, Кцэр, Ирк, Цвэрк, Црук, Мцрутзэнц, Црэдэ, Црав, Рин, Доц, Нцавдзо, Кцик, Цруш, Пцэк, Кцвотмоц, Зормцу, Кцанц, Даш, Цришцхик, Вук, Лэк, Дзрэрк, Дзрув, Тцо, Шрцк, Чрошат, Цшут, Цван, Цвуш, Кцвэт.

Выборка создана локальной реализацией тех же правил; при проверке 100 результатов получено 100 уникальных слов, одинаковых при повторном запуске с тем же зерном. Все прошли текущие программные проверки структуры.

## Выводы

- Стрекочущий характер заметен, особенно в коротких сочетаниях `Црурк`, `Пцоцк`, `Кцва`, `Цвэрк`.
- Некоторые формы всё ещё слишком напоминают случайное соединение слогов. Текущая проверка **не моделирует реальную артикуляцию** и не может установить, способен ли речевой аппарат синаптов произнести слово.
- Генератор **не переводит** и пока не привязывает смысл к корням. Для полноценного языка надо построить морфемы, синтаксис и ограничения на сочетаемость.
- Нельзя считать «прошло тесты» равнозначным «лингвистически правдоподобно». Дальше нужен ручной слуховой отбор и ограничение особенно тяжёлых сочетаний.

## Как воспроизвести

```bash
cd tools/linguistics/reboot
python phonotactics.py --count 40 --seed 42 --style chitter
python phonotactics.py --count 40 --seed 42 --style balanced
python -m unittest discover -s . -p 'test_phonotactics.py' -v
```

**Следующий этап:** выделить 10–15 удачных звуковых структур, задать вероятность их использования, затем отдельно разработать морфемы и проверять новые сложные слова на фонотактику.
