# Морфология v0.2 — совмещение моделей

**Статус:** эксперимент, разработка с нуля. Ни прежние суффиксы, ни названия, ни этнонимы не считаются утверждёнными. Вся морфология ниже условная, пока мы не выбрали окончательную грамматику.

## Основной принцип

**Сложение корней создаёт новое понятие; суффиксы изменяют форму слова; приставки уточняют действие.**

Это смешанная агглютинативная модель: каждый грамматический элемент располагается в предсказуемом месте и обычно имеет одно значение. Такая схема логична и удобна для системы именования техники.

### Порядок

Для существительного:

`[определяющий корень + соединитель -и-] + главный корень + словообразовательный суффикс + число + падеж`

Для глагола:

`отрицание + вид + глагольный корень + время`

Включено не всё сразу — суффикс или приставка опускаются, если их значение не требуется.

## Рабочие аффиксы (все предварительные)

| Категория | Маркер | Пример | Значение |
|---|---|---|---|
| Исполнитель действия | -ик | дзримик | обнаруживающий |
| Инструмент | -ац | дзримац | прибор обнаружения |
| Событие / процесс | -э | дзримэ | процесс обнаружения |
| Место действия | -ор | дзримор | место обнаружения |
| Множественное число | -к | дзримк | несколько объектов |
| Винительный падеж | -эс | дзримэс | объект действия |
| Родительный падеж | -эн | дзримэн | принадлежность |
| Дательный падеж | -ир | дзримир | адресат / цель |
| Местный падеж | -эц | дзримэц | место |
| Творительный / инструментальный | -ум | дзримум | с помощью чего-либо |
| Настоящее время | -а | дзрима | действие в настоящем |
| Прошедшее время | -ит | дзримит | действие в прошлом |
| Будущее время | -ор | дзримор | действие в будущем |
| Отрицание | шэ- | шэдзримит | не обнаружил |
| Продолженное действие | мэ- | мэдзрима | находится в процессе обнаружения |

**Совпадающие формы `-ор` (место и будущее время) разделяются по частям речи, но это стоит проверить на неоднозначность живой речи.**

В будущих версиях надо исследовать фонологические изменения на границах морфем: так `дзримкэс` не обязательно должно остаться неизменным, если синаптскому аппарату неудобно произносить `мк`.

## Показательный разбор

`цвэк-и-дзрим-ац-к-эц`:

- `цвэк` — сигнал / передавать
- `-и-` — соединитель корней
- `дзрим` — обнаруживать
- `-ац` — устройство
- `-к` — множественное число
- `-эц` — местный падеж

Условно: «в нескольких устройствах обнаружения сигналов».

Это **демонстрация структуры**, не утверждённый перевод фразы. Словарные значения экспериментальны.

## Грамматический прототип

Для теста добавлен порядок **подлежащее — дополнение — глагол (SOV)**. Он пока не утверждён.

`мцэр цвэкэс дзримит`

Условная расшифровка: «личность обнаружила сигнал» (личность-ИМ. / сигнал-ВИН. / обнаружить-ПРОШ.). В реальном языке ещё потребуется согласовать семантику глагольного корня, лицо и другие формы.
