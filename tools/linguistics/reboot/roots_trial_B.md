# Синаптский язык с нуля: пробные корни — серия Б («стрекочущая»)

**Статус:** фонетический эксперимент; ни один корень или значение не является каноном. Создано в ответ на пожелание усилить сочетания **мц, цр, кц** и родственные последовательности. Не используем названия из прежних версий как обязательные эталоны.

## Правила формирования серии

- Основной характер — быстрые аффрикаты /ц дз ч/ плюс носовые, смычные и сонорные.
- Короткие слова с 1–2 слоговыми ядрами; некоторые имеют слогообразующие р/н.
- Большинство слов с заметным кластером, но есть простые слова, иначе язык монотонен.
- Русская запись условная: последовательности вроде «кц» требуют дальнейшей проверки артикуляции. Никаких декоративных апострофов.
- Значение назначено для пробы лексики, а не выведено из земного перевода.

## Проверочные сочетания (не готовые предложения)

- «Мцэр Кцэн» — личность + мышление.
- «Нцор Кцрав» — движение + путь.
- «Мдзар Цвэк» — хранить + передавать.
- «Црав Ндзэ» — группа + совместно.

## Вопросы к проверке

1. Насколько отличимы пары «Мцэр / Нцэр», «Кцэн / Пцэн» в быстрой речи? Не делать фонологически похожие слова техническими терминами одного класса.
2. Слишком ли часты начальные аффрикаты? Нужны ли слова с нейтральным началом?
3. Какие из сочетаний **кц, пц, тц** действительно удобны для биологического аппарата синаптов? Пока это гипотезы, не подтверждённые фонемные последовательности.
4. Не начинают ли слова звучать одинаково? По результатам стоит варьировать окончания и гласные.
5. Выбрать небольшой набор характерных кластеров и затем определить **продуктивные модели слогов**, до массовой генерации имён.

**Следующий шаг:** сравнить серии A и Б вслух/в чтении; затем утвердить ограничения на кластеры, а не отдельные слова автоматически.
