# Синаптский язык: игровой лексикон и минимальная система именования

**Дата:** 22.11.2026. **Статус:** рабочая схема, не утверждённые новые морфемы. Не вводить длинные диалоги как обязательную цель языка. Автор указал точные сферы использования: самоназвание; планеты, звёзды, сектора, спутники; география, города; уникальные институты; личные имена; классы кораблей; идиомы, ругательства; специальные понятия.

## 1. Уже выбранные и не выбранные формы
- **Црэмин** — родная планета, **Мцаш** — родная звезда; формы выбраны автором, этимологии ещё нет. В GameDoc могут оставаться старые редакционные названия до согласованной замены.
- Предыдущие личные имена и прочие планеты/звёзды/сектора — **звуковые пробы**, даже если автору в целом нравится их стиль; не объявлять весь список каноном.
- В фонетике разрешено начальное **ндз**, отклонены начальное **чв** и конечное **м**; заметно **уменьшить частотность шипящих**, но не исключать ш вообще (Мцаш).
- Не навязывать древнему языку модель «плавный до редукции»: речевой комплекс с хитиновым стрекочущим артикулятором и параллельной тимбальной коммуникацией уже согласован в расовой статье.

## 2. Два независимых слоя проектирования

**Слой А — имена по звучанию:** утверждённая форма, категория, допустимые звуковые последовательности, приблизительный исторический пласт и статус автора.

**Слой Б — этимология/семантика:** реконструируемые корни, их древние значения, смысловые изменения, словообразовательная модель, источник (свой/заимствованный/неясный), степень уверенности.

Не подгонять Б под А одним индивидуальным звуковым законом на каждое имя. Не навязывать каждому древнему топониму прозрачный современный перевод. Модели составных слов — только для реально составных именований.

## 3. Рабочие традиции именования

| Категория | Рекомендуемый механизм | Что не делать |
| --- | --- | --- |
| Самоназвание народа | Исторический этноним, возможный переход от названия общности или самоопределения; число и формы обсуждать отдельно | Не изобретать суффикс множественного только ради этнонима |
| Личные имена | Смешение старых неразложимых имён и исторически производных имён, реальные варианты длины и диалектные окончания | Не склеивать два случайных корня для каждого имени; не вводить половые суффиксы |
| Планеты | Древние локальные топонимы, перенос географического названия, колониальные посвящения, новые описательные образования | Не использовать единый суффикс «планета» для всех миров |
| Звёзды | Часть — очень древние короткие слова, часть — поздние каталожные и по имени местного наблюдения | Не делать названия всех звёзд аналогами названий планет |
| Спутники | Отношение к планете, видимый феномен, древняя местная лексика или поздняя астрономическая номинация | Не требовать одного шаблона у всех спутников |
| Сектора/созвездия | Широкие пространственные категории: старые образы наблюдателей vs. новые навигационные термины | Не смешивать сектор карты и рисунок звёздного неба |
| Регионы и города | Ландшафт, ресурсы, дороги, поселения, старые субстратные имена, институты | Не давать всем географическим именам одинаковый корень «место» |
| Институты | Устойчивое сложение смысловых основ или исторические термины, утратившие прозрачность | Не переводить слово-в-слово современные русские названия |
| Классы кораблей | Собственная система именования по функциям, поведению, природе, традиции инженерных школ; затем классовая морфология при необходимости | Не генерировать названия классов как набор случайных личных имён |
| Идиомы | Образы биологии, среды, спора, репутации, ошибок измерения, коммуникации; с пометкой буквального и переносного смысла | Не калькировать русские пословицы |
| Ругательства | Собственные культурные табу, личная компетентность, нарушение доверия/контракта; диапазон грубости и регистра | Не сводить к репродуктивной/половой лексике людей |
| Особые понятия | Исторические семантические сдвиги и техническое словообразование | Не выдавать случайный звукоряд за термин без смысловой сети |

## 4. Первые 30 *семантических ячеек* для последующего словаря

Это **значения для тестирования**, а не назначенные звуковые корни. Они позволят проверить, насколько удачны слова и можно ли из них естественно образовывать новые.

### Среда и наблюдение (1–10)
1. твёрдая поверхность / опора
2. трещина / проход между преградами
3. тепло / источник тепла
4. вода / влажность
5. камень / минерал
6. рост / живое
7. свет / источник света
8. тень / закрытость
9. верх / над
10. край / граница

### Действия и отношения (11–20)
11. движение / перемещение
12. путь / направление
13. сходиться / встречаться
14. разъединяться / расходиться
15. передавать / обмениваться
16. хранить / удерживать
17. обнаруживать / замечать
18. различать / сравнивать
19. связывать / соединять
20. принадлежать / быть своим

### Социальные и познавательные понятия (21–30)
21. отдельная особь / личность
22. временное объединение / совместное действие
23. договор / согласованное обязательство
24. свидетельство / основание утверждения
25. ошибка / расхождение с фактом
26. спор / проверка тезиса
27. наставничество / обучение
28. мастерство / компетентность
29. установка / искусственно созданная функция
30. последовательность / закономерность

Некоторые русские глоссы частично перекрываются намеренно: сначала проверить, какие различия важны **синаптам**, а не автоматически создавать отдельный корень на каждый русский синоним. Можно слить или разделить ячейки после смысловой проверки.

## 5. Словообразовательный минимум: сначала функции, затем фонетические суффиксы

Проверять в следующем порядке:
1. **Корень + корень** для устойчивого природного/общественного понятия и топонима, если он действительно разложим.
2. **Корень + локативный дериват** для учреждения, места работы или регулярного действия. Не путать с **падежом места**.
3. **Корень + деятель/носитель функции** для имён профессий, должностей и технических классов.
4. **Корень + орудие/изделие** для оборудования и классов кораблей, когда такая схема вообще продуктивна.
5. **Корень + абстрактное понятие/результат** для научной и социально-правовой лексики.
6. **Фиксированные словосочетания** (идиомы) не считать одним словом без исторического основания.

`affix_catalog_v03.md` содержит кандидатные `-ор`, `-ик`, `-ац`, `-энц`, `-ут` и другие; это **только лабораторные варианты**. Падежи `-эс`, `-эн`, `-эц` и т. д. не создают сами по себе географические имена.

## 6. Первые конкретные проекты по категориям (без новых неутверждённых слов)
- **Планета Црэмин:** проверить три конкурирующие гипотезы — исходный региональный топоним; составное название местности; древнее непрозрачное заимствование. Региональный перенос ранее обсуждён и принят как основа; буквальный перевод ещё не утверждён.
- **Звезда Мцаш:** определить древний статус, возможную самостоятельную корневую форму и роль шипящего `ш` как редкой, но допустимой конечной фонемы. Не требовать симметричной этимологии с Црэмином.
- **Самоназвание народа:** прежде предложить отдельную звуковую партию, без старого «Тнацш».
- **Новые миры/спутники/сектора:** сделать звуковые серии по разным традициям и затем связать их с ограниченным набором семантических ячеек.
- **Институты и корабельные классы:** прежде составить список реально существующих институтов и классов из GameDoc; не заполнять несуществующие категории выдуманными терминами.

## 7. Проверка пригодности для игры
Для каждой словарной единицы хранить: `id; type; display_ru; pronunciation; morphology; gloss; era; region/dialect; etymology; evidence; status; related_entities`. Отдельно считать частоты начальных кластеров, шипящих, финальных согласных, совпадений и похожих форм. Проверять допустимость по `phonotactics.py`, но не считать генератор готовой исторической грамматикой.

**Критерий успеха:** если игрок видит 20 личных имён, 10 миров, 5 институтов и 5 классов кораблей, они узнаваемо синаптские, но **не выглядят случайными вариантами одного слова**.

## 8. Непосредственно следующий этап
1. Выбрать 8–12 семантических ячеек из списка для первой фонетически мотивированной партии **современных корней** (не древних).
2. Сопоставить с уже приятными по звучанию формами и ограничить омонимию.
3. Для 3–4 корней продемонстрировать образцы сложений **по существующим пробным моделям**, ясно маркируя неканоничность.
4. Лишь после проверки этих слов переходить к ранней системе фонем и регулярным историческим изменениям на полном наборе корней.
5. Параллельно обновлять `../language_development_pipeline.md` для использования другими расами.
