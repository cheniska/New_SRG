# Ндзеракский: вопросительные местоименные основы G6

**Дата:** 25.11.2026. **Статус:** новый тестовый набор после утверждения личных местоимений [G4](pronoun_roots_selection_G4_2026-11-25.md) и принятия форм **Зэ** (притяжательная связь) и **Дзрэн** (возвратность) в [G5](reflexive_possessive_pronouns_trial_G5_2026-11-25.md). **Ни одна вопросительная форма ниже пока не утверждена автором.** Синтаксис SOV/SVO остаётся открытым.

## 1. Рекомендуемое семейство A: Цвэр-

| Вопрос | Рабочая форма | Узкая смысловая область | Ограничение |
|---|---|---|---|
| Кто? | **Цвэри** | «какая особь / участник / агент?»; не обязательно только представитель своей расы | Вопрос о лице/участнике, не о биологическом виде |
| Что? | **Цвэра** | «какой предмет, явление или событие?» | Не автоматически «почему» / «что произошло?» |
| Который? Какой из известных? | **Цвэрин** | выбор из определённой группы, идентификация варианта | Не всё прилагательное «какой по качествам»; последнее потребуется отдельно |
| Чей? | **Цвэри зэ** | чья принадлежность / связь с каким участником? | Использует уже принятую форму **Зэ**; **не отдельный четвёртый корень** |

Это **не** объявляет `цвэр-` доказанным древним корнем и не утверждает морфемы `-и`, `-а`, `-ин`. Но семантически близкие запросы могут формировать узнаваемую синхронную группу. **Цвэра / Цвэри** отличаются последней гласной: это намеренное близкое звучание близких категорий, требующее испытания быстрой речи; если различие окажется слабым, следует менять одну форму.

**Цо** из G3/V2 — рабочая **вопросительная частица для вопросов «да/нет»**, пока ещё не утверждённая; её не следует механически добавлять к вопросам с Цвэри/Цвэра без проверки грамматики. Не путать вопросительные местоимения с базовыми `Цвэк` («переданный сигнал»), `Цвирак` («ошибка») и `Вэр` («образовывать покров»). Созвучие не доказывает их этимологического родства.

## 2. Альтернативное семейство B для звукового сравнения

| Вопрос | Альтернатива |
|---|---|
| Кто? | **Нцура** |
| Что? | **Нцурэ** |
| Который? | **Нцурин** |
| Чей? | **Нцура зэ** |

Вариант B ближе к тройке утверждённых корней **Кцур** (разлом), **Мцур** (вода) и **Пцур** (фильтрация); по семантике вопросительные местоимения не связаны с этими процессами. Поэтому **вариант A предпочтительнее**, а B только фонетическая альтернатива, не автоматическое пополнение словаря.

## 3. Предварительная проверка форм

- Кандидаты A: **Цвэри, Цвэра, Цвэрин** образуются из допустимых слогов (`цв-э + р-и`, `цв-э + р-а`, `цв-э + р-и-н`). Конечные гласные/сонорные допустимы.
- По первичной проверке кириллических написаний все три формы A **не совпадают** с выбранными 40 корнями или активной G3/G4 лексикой и не отличаются от этих уже выбранных форм всего одним знаком. Сравнение на акустическом/вибрационном уровне ещё не проводилось.
- Между собой формы **очевидно близки**. Это *задуманный* связанный морфологический ряд в настоящем языке, но не доказательство общей древней основы; особое внимание на различение Цвэри и Цвэра.
- **«Чей?»** на первое время не имеет новой лексемы: предполагается вопросительное слово **Цвэри** с ранее принятой частицей **Зэ**; точный порядок вопросительной группы и самостоятельность Зэ не утверждены.

## 4. Небольшие тесты на игровых объектах

Вопросительные строки — **лексико-синтаксические эскизы**; не утверждать порядок слов, вопросы без частицы или предикацию без связки.

| Проба | Ожидаемый смысл | Невыясненное |
|---|---|---|
| **Цвэри?** | Кто? | Достаточно ли одиночного вопросительного слова? |
| **Цвэра?** | Что? | Может ли слово задавать вопрос о событии? |
| **Цвэрин цворэт?** | Которое изделие? | Порядок определения и существительного |
| **Цвэри зэ цворэт?** | Чьё изделие? | Статус Зэ и порядок группы |
| **Цвэри цвэк ндзонэ?** | Кто получил сигнал? | Вопросительное подлежащее, порядок сказуемого |
| **Дзэру цвэра дзрина?** | Что ты замечаешь? | Место вопросительного дополнения в предложении |

## 5. Статус и дальнейшая работа

**Не менять утверждённые** Мцари / Мцэни, Дзэру / Дзэрцэ, Дзорон / Дзорац, Ицэ / Ицэв, Зэ, Дзрэн, Эцан и 40 базовых корней из-за выбранного вопросительного семейства. Сначала авторский отбор звучания, затем отдельный тест «что за? / какой по качествам?», «где / куда», «когда», «почему» и грамматического расположения вопросительных слов. Не создавать полный набор из десяти форм, пока не выбрана система первых трёх.
