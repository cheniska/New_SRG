# Пробные корни синаптского языка — чистая серия A

**Статус:** лабораторная подборка; ни один корень не утверждён. **Не использовать ранее согласованные названия** как фонетические эталоны. Корни искусственно построены по новой фонотактике, а не переводятся из грузинского.

## Обозначения

Русская запись передаёт приблизительное звучание. В технических комментариях `/r̩/` и `/n̩/` — слогообразующие сонорные (в обычной записи дополнительного знака нет). Сочетания типа `крн` и `тнк` требуют дальнейшей артикуляционной проверки; наличие слогового сонорного **не делает автоматически допустимой любую группу согласных**.

## Лабораторный набор смысловых корней

| № | Значение | Форма | Структура / примечание |
|---|---|---|---|
| 1 | особь, отдельное «я» | **дрэ** | смычный + сонорный + гласная |
| 2 | другой, внешний | **шэк** | шумный начальный + закрытый слог |
| 3 | группа, собравшиеся | **мцэн** | носовой + аффриката, завершение сонорным |
| 4 | мыслить, различать | **крн** | слогообразующий `/r̩/`, финальный носовой |
| 5 | узнавать, обнаружить | **дзрэ** | аффриката + сонорный + гласная |
| 6 | хранить, удерживать | **грав** | смычный + сонорный; закрытое окончание |
| 7 | передавать, посылать | **псрэ** | сложный начальный кластер, требует проверки |
| 8 | двигаться, проходить | **трог** | обычный закрытый слог |
| 9 | место, участок | **цэр** | аффриката + гласная + сонорный |
| 10 | большое, обширное | **квэш** | двухсогласное начало + щелевой конец |
| 11 | свет, излучать | **зрэк** | щелевой + сонорный, закрытый слог |
| 12 | убежище, укрывать | **тнк** | слогообразующий `/n̩/`, финальный смычный; проверять |
| 13 | живое, расти | **нэгр** | носовой + закрытый конечный кластер |
| 14 | опасность, угроза | **кхор** | заднеязычный щелевой кластер (точная фонема не утверждена) |

**Не канон:** значения назначены для испытания сочетаний звуков, без выдуманной истории языка. Прежде чем утверждать словарь, нужно оценить произносимость, количество повторов и совместимость с артикуляцией.

## Примеры только для слуховой оценки

- `дрэ мцэн` — «я / группа» (два независимых корня, **не грамматическое предложение**).
- `дзрэ шэк` — «обнаружить / другое» (**не перевод фразы**, порядок слов не утверждён).
- `псрэ трог` — «передавать / двигаться».
- `зрэк цэр` — «свет / место».

## Что нужно решить далее

1. Предпочтительные звуковые кластеры: например `дзр`, `мц`, `пср`; какие искусственны.
2. Доля слов со слоговыми `р` и `н` в живой речи — частые или редкие.
3. Ограничения на неразличимые в русской записи вибрационные контрасты.
4. Затем — морфемы, грамматика и словосложение; **не создавать названия рас, планет, звёзд и классов кораблей до проверки этой основы**.
