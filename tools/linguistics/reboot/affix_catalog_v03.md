# Синаптский язык (перезапуск): морфология, подробные таблицы v0.3

**Статус:** рабочий конструктор грамматики, а не канон. Все корни, суффиксы и приставки здесь экспериментальны. Ранее утверждавшиеся этнонимы, топонимы и имена НЕ используются как критерии. Цель — создать словарь сложных технических слов, но не склеивать целые предложения.

## 1. Три уровня: не путать

1. **Словообразование:** `дзрим` (обнаруживать) + `-ац` (устройство) → **дзримац** («детектор»).
2. **Словосложение:** `цвэк` (сигнал) + соединитель `-и-` + `дзрим` + `-ац` → **цвэкидзримац** («детектор сигналов»). Это **один лексический термин**, допустимый в словаре.
3. **Словоизменение:** `цвэкидзримац` + `-к` (множественное) + `-эц` (местный падеж) → **цвэкидзримацкэц** («в детекторах сигналов»). Суффикс **-эц** не является частью названия прибора: он появляется только по требованию предложения. Если произносимость неудобна, позднее вводим закономерное правило стыка морфем, а не меняем смысл.

Отдельный корень со значением «место» к техническому термину присоединять не нужно. **Слово `цхэм` («место») не добавляется** в приведённом примере.

## 2. Базовая архитектура

- Существительное: `[корень-(и-корень)]-[словообразовательный суффикс]-[число]-[падеж]`.
- Глагол: `[отрицание]-[способ протекания]-корень-[время]-[наклонение]`.
- Суффиксы — грамматические показатели и некоторые продуктивные производные; приставки — преимущественно изменение действия.
- Обычная синтаксическая связь между разными объектами остаётся **разными словами**. Не каждое русское словосочетание автоматически превращается в одно слово.
- Корневое сложение допускается, когда сочетание обозначает самостоятельный устойчивый вид предмета/процесса (научный прибор, профессия, тип корабля). Внесение в словарь требует отдельного решения.
- У вида нет разделения на мужской и женский пол, поэтому обязательный грамматический род не вводится.

## 3. Число существительных

| Категория | Суффикс | Функция | Пример |
|---|---|---|---|
| Немаркированное / единичное | Ø | Один либо число из контекста | дзримац |
| Множественное | -к | Несколько индивидуальных объектов | дзримацк |
| Собирательное | -ум | Комплект или совокупность как целое | дзримацум |

**Слоты взаимоисключающие**: -к и -ум не ставятся вместе. При числительном число может оставаться немаркированным — вопрос к будущему синтаксису.

## 4. Падежи существительных

| Падеж | Суффикс | Значение | Пример |
|---|---|---|---|
| Прямой | Ø | Подлежащее, словарная форма | дзримац |
| Объектный (винительный) | -эс | Прямой объект действия | дзримацэс |
| Родительный | -эн | Принадлежность, отношение к предмету | цвэкэн дзримац |
| Дательный | -ир | Получатель, адресат | мцэрир |
| Местный | -эц | Нахождение где-либо | цхэмэц |
| Исходный | -аш | Откуда, из чего | цхэмаш |
| Направительный | -уц | Куда, к чему | цхэмуц |
| Орудийный | -ов | С помощью чего | дзримацов |
| Совместный | -ил | Вместе с кем | мцэрил |

Суффикс падежа применяется к **целому слову после словообразования и числа**. Например, `цвэкидзримац-эц` — «в детекторе сигналов»; не «детектор места». Пространственные значения вроде «над», «за», «между» позднее можно выражать отдельными послелогами.

## 5. Словообразовательные суффиксы (не падежи)

| Смысл | Суффикс | Пример | Для чего |
|---|---|---|---|
| Основной корень | Ø | дзрим | Базовая форма |
| Действующее лицо / агент | -ик | дзримик | Тот, кто обнаруживает |
| Прибор / инструмент | -ац | дзримац | Детектор |
| Процесс / событие | -э | дзримэ | Обнаружение как процесс |
| Место, специально предназначенное для действия | -ор | дзримор | Пункт обнаружения / наблюдательная станция |
| Абстрактное качество | -энц | кцэнэнц | Способность / качество мышления |
| Результат действия | -ут | дзримут | Результат обнаружения |
| Материал / вещество, связанное с корнем | -ис | цшарис | Условный термин, смысл зависит от корня |
| Принадлежность / свойство (образование определения) | -ив | цвэкив | Сигнальный, относящийся к сигналу |
| Уменьшительность (не обязательная) | -эцр | дзримацэцр | Малый вариант устройства |

**Внимание:** -ор одновременно использовалось как показатель будущего времени в старом эксперименте. В новой схеме этот конфликт снимаем: время будущего получает **-ав**, а -ор сохраняем исключительно для словообразования места. Другое совпадение: -ум (собирательное) отличается от -ов (орудийный), -ац (инструмент) отличается от -уц (направительный).

## 6. Время и вид глагола

| Категория | Маркер | Образец от `дзрим` | Пояснение |
|---|---|---|---|
| Настоящее | -а | дзрима | Совпадает с моментом речи / привычное действие |
| Прошедшее | -ит | дзримит | Предшествует моменту речи |
| Будущее | -ав | дзримав | Последует за моментом речи |
| Вневременное / словарный корень | Ø | дзрим | Словарная форма, не свободный финитный глагол |
| Нейтральный вид | Ø | дзрим-а | Вид без дополнительного указания |
| Продолжающееся действие | приставка мэ- | мэдзрима | Действие находится в процессе |
| Завершённое действие | приставка кэ- | кэдзримит | Действие достигло естественного результата |
| Повторяющееся / привычное | приставка цэ- | цэдзрима | Повторяемость |

Выбор видов является рабочей гипотезой; «прошедшее» не всегда означает «завершённое».

## 7. Приставки смысла и отрицания

| Категория | Приставка | Образец | Значение |
|---|---|---|---|
| Утверждение | Ø | дзрима | Утвердительная форма |
| Отрицание | шэ- | шэдзрима | Не обнаруживает |
| Начало действия | нэ- | нэдзрима | Начинает обнаруживать |
| Повтор действия | рэ- | рэдзрима | Обнаруживает вновь |
| Совместное действие | мцэ- | мцэдзрима | Обнаруживает совместно |
| Направленное наружу | цу- | цудзрима | Направленность действия наружу (не для всех глаголов) |
| Направленное внутрь | кэ- | кэдзрима | Направленность действия внутрь (конфликт с видом «завершено»!) |

**Конфликт кэ-**: две разные категории получают одну форму. Не закреплять одновременно. В текущем рабочем наборе оставляем **кэ- только для завершённого вида**, а направление внутрь передаём отдельным обстоятельством, пока не разработаны пространственные приставки. Позиция приставок: **ОТРИЦАНИЕ → ВИД/АКЦИОНАЛЬНОСТЬ → КОРЕНЬ → ВРЕМЯ**. Несколько приставок вида одновременно пока запрещены.

## 8. Наклонение / модальность

| Значение | Суффикс после времени | Пример | Статус |
|---|---|---|---|
| Изъявительное | Ø | дзримит | Рабочее |
| Повелительное | -эц | дзримаэц | Рабочее, требует фонетической обработки стыка |
| Условное («если бы») | -аш | дзримиташ | Рабочее |
| Желательное | -ир | дзримавир | Рабочее |
| Возможность / необходимость | отдельные слова | — | Предпочтительно как служебные конструкции, не дополнительные суффиксы |

Падежные и глагольные суффиксы могут совпадать по звучанию, потому что относятся к разным частям речи; **но** такие совпадения надо проверить на неоднозначность в реальной фразе.

## 9. Категории, которые нужны для полноты, но пока не следует выдумывать окончания

| Область | Предварительное решение |
|---|---|
| Лицо глагола (я/ты/он) | Явное местоимение либо суффикс; проверить, нужно ли согласование вообще |
| Вопрос | Отдельная вопросительная частица |
| Отрицание существительного | Отдельное слово (не глагольная приставка) |
| Относительные предложения | Отдельный союз/маркер |
| Прилагательные | Отдельные слова или производные на -ив; согласование пока не вводить |
| Степени сравнения | Частицы, не набор новых падежей |
| Числительные | Отдельные лексемы; система счёта пока не разработана |
| Обращение | Отдельная интонация/частица; звательный падеж не обязателен |
| Деепричастия, причастия | Исследовать позже, когда появятся реальные предложения |
| Указательные, личные, притяжательные местоимения | Малый закрытый словарь; притяжательность через родительный |
| Вибрационный контраст | Отдельный слой записи, не обычная приставка или суффикс |

## 10. Проверки перед канонизацией

1. Создать валидатор морфемных границ, чтобы сочетания `мк`, `цк`, `цацк` не превращались в неудобопроизносимые слова.
2. Ввести предсказуемые правила ассимиляции и вставки гласной только при необходимости.
3. Проверить, не дают ли разные комбинации одинаковую итоговую форму.
4. Протестировать десять полноценных предложений, включая отрицание, несколько падежей, времена и сложные существительные.
5. Выбрать ограничения на словообразование: какие соединения становятся отдельными словарными единицами.

**Важно:** существующий `morphology_v2.py` содержит ранний неполный набор и пока не соответствует всей этой таблице; следующее обновление движка должно использовать единую декларативную таблицу правил, а не дублировать окончания по нескольким местам.
