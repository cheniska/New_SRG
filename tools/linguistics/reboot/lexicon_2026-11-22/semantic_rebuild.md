# Семантическая ревизия синаптского игрового языка — 22.11.2026

**Статус:** новая рабочая методика и проработанная серия биологических наименований; новые корни, слова и суффиксы пока **НЕ канон**. Исходный [каталог 160 форм](README.md) — звуковой архив, **не готовый лексикон**. Разработку нельзя считать завершённой присвоением случайного слова заранее выбранному объекту.

## 1. Обязательные условия для каждого нового имени

Прежде чем сформировать слово:
1. **Референт:** конкретный объект в GameDoc; различать реально описанный вид, местное народное название, гипотетическую разновидность и потенциально новый вид.
2. **Воспринимаемое синаптами свойство:** экология, способ существования, взаимодействие с другими организмами, практическая роль, историческая оценка, а не только человеческий внешний вид.
3. **Историческое именование:** древнее местное имя, перенос названия, устойчивое описательное сложение, научный термин, прозвище, заимствование. Не всем объектам нужны прозрачные составные слова.
4. **Семантическая цепочка:** буквальная внутренняя форма → механизм переосмысления → сегодняшнее значение.
5. **Формообразование:** употреблять морфемы из общего словаря с одинаковыми значениями, фиксировать продуктивность и ограничения; `-ик` «носитель действия» и `-и-` «соединитель» пока исключительно кандидаты из `affix_catalog_v03.md`.
6. **Фонология:** проверка корней, составных основ и морфемных стыков; отдельно — игровой вид написания. Нельзя считать произвольное словосложение автоматически допустимым только потому, что его компоненты хороши.
7. **Статус:** предложено, принято по звучанию, утверждено как морфема, утверждена этимология, канон. Не смешивать статусы.

Для личных имён нужно дополнительно фиксировать историческую традицию именования и её связь с родителями/школами без преждевременного обязательного фамильного суффикса. Для идиом — буквальную фразу, переносное значение, прагматику и степень грубости.

## 2. Небольшое расширение семантических корней для биосферы

| Основа | Рабочее исходное значение | Откуда могла возникнуть семантика |
|---|---|---|
| `нэв` | симбиотическое переплетение, единое тело из множества взаимосвязанных частей | микосферы состоят из больших симбиотических комплексов |
| `вэр` | стелиться, покрывать тонким слоем | скальный ковёр |
| `гэц` | накапливать металлы из среды | металлофильные организмы |
| `кцор` | затаиться, оставаться неподвижным ради захвата | засадные формы жизни |
| `дэв` | собирать пригодные плодовые тела / ресурсы | образ жизни предков синаптов и их родственника |
| `вар` | прилив, приходящая масса, волна | массовые сезонные скопления мелководной фауны; точная сезонность не установлена |
| `пцур` | фильтровать поток | глубоководный фильтратор |
| `тар` | рыть, продвигаться сквозь рыхлую среду | роющая гексапода |
| `вир` | приманивать, направлять внимание к источнику | летучие аттрактанты хищного организма |
| `тэмар` | долго сохранять деятельность, медленно протекать | культурный образ древней линии фильтраторов |

Вместе с ранее испытанными `мцив` (живое, рост), `гар` (камень), `мцур` (вода), `црэван` (твёрдая опора), `нцэрат` (тень), `ндзэ` (совместность), `мцэр` (особь) это позволяет моделировать **семантические семейства**, а не по отдельному случайному имени на вид.

### Словообразовательные правила-кандидаты

- `A-и-B`: связанное обозначение «B, характеризующееся A», где A уточняет экологическую черту или материал; **не универсальный падеж или правило всех имён**. Пример: `гар-и-вэр` — стелющийся каменный покров.
- `A-ик`: живой носитель характерного действия; пример `пцур-ик` — фильтрующий. Возможность расширения суффикса на фауну требует отдельного решения.
- Двусловное описательное имя (например, `тэмар пцурик`) используется как **модель народного эпитета**, а не готовая грамматическая фраза; синтаксис определения в речи надо проверить.
- Имена вида могут со временем утрачивать прозрачность. Народное название и научное обозначение не должны автоматически совпадать.

## 5. Как это переносится на остальные категории

| Категория | Что сначала извлечь из лора | Какую семантику проектировать |
|---|---|---|
| Самоназвание | самопонимание синаптов, индивидуализм и добровольное объединение | исторический этноним, не обязательно «разумные» |
| Личные имена | родители дают имя при вылуплении, нет полов, школы не наследуются как родовые линии | имена от наблюдаемых качеств/событий, древние непрозрачные имена и семейные традиции без половых окончаний |
| Планеты | влажность, геология, ценность исследований, история колонизации | ранние местные топонимы, поздние мотивированные колониальные имена |
| Звёзды | наблюдаемая яркость, цвет, периодичность и навигационная роль | астрономический образ, затем научное/каталожное обозначение |
| Сектора | направление освоения, навигация, исторические маршруты | технические зоны, не обязанные повторять созвездия |
| Созвездия | реальные очертания и культурные образы наблюдателя Црэмина | образы микосфер, засад, скоплений, изменения и связи; без бессмысленных произвольных созвездий |
| Спутники | внешний вид, орбитальные свойства, хозяйственное значение | народные и поздние астрономические имена |
| Географические регионы | микосферные леса, геотермальные поля, скалы, вода | устойчивые физические и хозяйственные признаки |
| Города | школа, геотермальное хозяйство, биополимерная архитектура, порт или научная функция | топоним с закреплённой историей основания, иногда от более древнего района |
| Институты | реально существующие советы, Сеть, школы, контрактный арбитраж, монарх | название устойчивой *функции*, иногда метонимическое наследие |
| Классы кораблей | реально заданная функция корабля и инженерная традиция | роль/назначение, метафора движения/наблюдения, а не случайный звук |
| Идиомы | биология и общественное значение проверяемого знания | буквальный образ → переносное значение → контекст употребления |
| Ругательства | отношение к неточным данным, нарушенным договорам, лжи и некомпетентности | степень оскорбительности и культурное табу, без заимствования человеческих половых ругательств |
| Специальные понятия | Сеть, научные школы, автономия колоний, этика интерпретируемого ИИ | термины, не сводимые к калькам современных человеческих слов |

## 6. Минимальный реестр каждой будущей записи

`id; референт; вид объекта; источник в лоре; название; морфемы; буквальная глосса; современное значение; исторический пласт; народное/официальное/научное употребление; фонетическая проверка; статус; близкие названия`.

Требования к каждой партии: минимум два разных механизма именования, ни одного произвольно приписанного перевода, соблюдение запрета `чв-` и финального `-м`, редкость шипящих, отличимость от уже утверждённых Црэмина и Мцаша. Фонетическая структура **не заменяет** семантического объяснения.

## 7. Что ещё нельзя считать решённым

- Новые десять биологических основ не прошли историческую реконструкцию, семантические значения ещё требует согласования.
- Некоторые формы многосложны; разбор их как **сложных слов** не равен ограничениям генератора одиночных корней. До игровой канонизации нужен тест фонетики стыков и распределения ударения.
- `-ик` и `-и-` остаются предложенными морфемами. `Ндзэтар` требует объяснения сложения без соединителя либо замены.
- Не утверждена биологическая классификация на основании этих имён.
- Оставшиеся 140 элементов из старого каталога — архивная звуковая партия, **их нельзя считать готовыми осмысленными словами**. Следующий проход требует отдельного обоснования каждого имени, а не механической подстановки.
