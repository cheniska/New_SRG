## Как обновляются страницы

Это экспериментальное представление существующих досье, а не второй независимый источник канона. Содержательные изменения вносятся в исходные статьи, затем страницы пересобираются:

```bash
python tools/docs/build_wiki_preview.py
```

Сохраняются полные тексты, постоянные адреса разделов и обозначения редакционных пробелов. Карточка переносится наверх, добавляются оглавление и ссылки на связанные статьи. Относительные Markdown-ссылки и стабильные адреса разделов позволяют позднее использовать этот материал на сайте; автоматическая сборка сайта пока не добавлена.
