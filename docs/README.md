# Документация New_SRG

| Папка | Что там |
|---|---|
| [`modules/`](modules/README.md) | **Техническая документация по коду**: архитектура и слои, ход, ИИ, бой, экономика, генерация, визуал, UI, сохранения, тесты, Lua-API. Начинать с [architecture.md](modules/architecture.md). |
| [`design/`](design/) | Геймдизайн и спецификации механик: формулы, оборудование, диалоги, траектории, спавн, наука, торговля. |
| [`reference/`](reference/) | Данные и исследования оригинальной игры (Space Rangers HD): тексты, скриптовые функции, диалоги, отчёт по ИИ. Справочно, не спецификация. |
| [`archive/`](archive/) | Устаревшие документы и черновики — сохранены для истории, не актуальны. |
| [`third_party_licenses.md`](third_party_licenses.md) | Лицензии сторонних библиотек. |

## Соглашения

- Технические документы — Markdown в `modules/`, по шаблону из [modules/README.md](modules/README.md).
- Имена файлов — латиницей, без пробелов и суффиксов вроде `(2)`.
- При переносе/переименовании кода обновлять пути в документах (`Assets/Scripts/...`).
