# Техническое задание: Планетарный и Галактический технический уровень
## 1. Планетарный технический уровень (ПТУ)
### 1.1 Общее описание
Каждая планета имеет параметр ПТУ в диапазоне (1–8).
### 1.2 Влияние ПТУ
- Участвует в расчёте ГТУ
- Определяет уровень оборудования в магазине планеты
- Определяет уровень оборудования у кораблей, рождающихся на планете
### 1.3 Скорость роста ПТУ
Скорость роста ПТУ вычисляется раз в N игровых месяцев (N задаётся конфигом).
Итоговая скорость = base_growth_rate × M_race × M_economy × M_government × M_population × M_lag × M_difficulty
Все множители хранятся в конфиге и могут быть изменены без правки кода.
#### Конфиг множителей (структура)
ptu:
  tick_months: 1                # как часто пересчитывается рост ПТУ
  base_growth_rate: 1.0         # базовая скорость (условные единицы прогресса в тик)
  race_modifiers: (вносятся как параметры каждой расы)
    malok: 0.6
    peleng: 0.8
    human: 1.0
    fayan: 1.2
    gaal: 1.5

  economy_modifiers: (вносятся как параметры каждой экономики)
    agrarian: 0.8
    mixed: 1.0
    industrial: 1.3

  government_modifiers: (вносятся как параметры каждого правительства)
    anarchy: 0.7
    dictatorship: 0.85
    monarchy: 1.0
    republic: 1.1
    democracy: 1.2
  population_formula: "logarithmic"  # тип формулы: linear / logarithmic / custom
  # Формула задаётся отдельным выражением или таблицей в конфиге
  lag_bonus: 1.5     # множитель для «отсталых» планет (ПТУ < ГТУ)
  difficulty_equipment_bonus:# множитель равен сложности, пока оставим 1
### 1.4 Кризисы
Кризисы — события, которые временно тормозят рост ПТУ и/или вызывают побочные эффекты.
Каждый кризис описывается записью в конфиге.
#### Конфиг кризисов (структура)
ptu:
  crises:
    - id: mineral_shortage
      display_name: "Нехватка минералов"
      growth_multiplier: 0.7       # сильное замедление роста ПТУ
      population_effect: 0.0       # изменение населения в тик (0 = нет эффекта)
      affects_economy: [industrial, mixed]  # для каких типов экономики эффект усилен

    - id: tech_shortage
      display_name: "Нехватка техники"
      growth_multiplier: 0.4
      population_effect: 0.0
      affects_economy: [agrarian,mixed]  # у аграрных особенно сильный эффект
      affects_economy_multiplier: 0.2, [agrarian]  # дополнительный штраф для указанных типов

    - id: medicine_shortage
      display_name: "Нехватка медикаментов / Эпидемия"
      growth_multiplier: 0.05      # рост почти заморожен
      population_effect: 0.1     # уменьшение скорости увеличения населения, при минусовых значениях население начинает уменьшаться

    - id: food_shortage
      display_name: "Нехватка еды / Голод"
      growth_multiplier: 0.05      # рост почти заморожен
      population_effect: -0.02     # убыль населения в тик

    - id: pirate_occupation
      display_name: "Захват пиратами"
      growth_multiplier: 0.6       # замедление роста
      population_effect: 0.0

    - id: dominator_occupation
      display_name: "Захват синтетами"
      growth_multiplier: 0.0       # рост полностью остановлен
      ptu_penalty: 1               # мгновенное снижение ПТУ на N уровней при захвате (уточнить)
      population_effect: -0.10     # резкое сокращение населения при захвате
```

Кризисы могут накладываться одновременно — эффекты перемножаются.

### 1.5 Механика исследований
- Каждая планета ведёт два независимых дерева исследований: **для NPC** и **для игрока**.
- Каждый ход планета получает очки прогресса (progress_points), рассчитанные по формуле из п. 1.3.
- Когда накопленный прогресс достигает порога технологии — она открывается.
- Следующее исследование выбирается **случайным образом** из доступных по правилам (см. ниже).
- Переход ПТУ на следующий уровень происходит, когда открыто достаточно технологий текущего уровня (порог задаётся конфигом).

#### Какие технологии исследуются — открытый вопрос

Необходимо определить и зафиксировать:
- Список всех технологий (по типам: корпус, двигатель, оружие и т.д.)
- Привязку каждой технологии к уровню ПТУ (I–VIII) - всегда изучаются технологии следующего от текущего ПТУ
- Правила случайного выбора следующего исследования (какие ограничения существуют)

**До принятия решения** реализацию дерева технологий отложить; заглушка: при достижении порога прогресса ПТУ повышается на 1.

#### Конфиг прогресса (структура-заглушка)

```yaml
ptu:
  research:
    progress_per_level: 100        # очков прогресса для перехода на следующий уровень ПТУ
    # В финальной реализации заменяется полноценным деревом технологий
```

## 2. Галактический технический уровень (ГТУ)

### 2.1 Общее описание

ГТУ — глобальный параметр галактики. Пересчитывается при каждом изменении ПТУ любой планеты содружества.

### 2.2 Алгоритм расчёта ГТУ

```
max_ptu    = максимальный ПТУ среди всех планет содружества
count_max  = количество планет с ПТУ == max_ptu

если count_max == 1:
    ГТУ = max_ptu - 2
если count_max в [2, 3, 4]:
    ГТУ = max_ptu - 1
если count_max >= 5:
    ГТУ = max_ptu

ГТУ = max(ГТУ, 1)   # нижний порог
```

Пороги (1 / 2–4 / 5+) выносятся в конфиг:

```yaml
gtu:
  thresholds:
    - min_planets: 1
      max_planets: 1
      penalty: 2
    - min_planets: 2
      max_planets: 4
      penalty: 1
    - min_planets: 5
      max_planets: null   # без верхней границы
      penalty: 0
  min_value: 1
```

### 2.3 Эффект падения ГТУ

Если одна из 5+ планет с max_ptu поднимается на уровень выше, она становится единственной с новым максимумом → ГТУ = new_max − 2, что на 1 ниже предыдущего ГТУ. Это **ожидаемое поведение**, не ошибка. Обработки не требует, но должно быть покрыто тестом.

### 2.4 Влияние ГТУ

- Определяет глобальное качество оборудования у всех кораблей (включая синтетов)
- Предмет с ТУ > ГТУ **никогда не выпадает** с уничтоженного корабля
- Для оружия дополнительно существует **нижний порог появления** по модели:
- оборудование с ТУ > ГТУ нельзя использовать и чинить.

все формулы должны быть вынесены в конфиг, как и коэффициенты
