2. АРХИТЕКТУРА VMT (Hex-Rays vs IDA адресация)
================================================================================

Delphi 7 VMT layout: runtime ClassRef pointer указывает на +0x4C (76 байт = 19
служебных DWORDs) от IDA-маркированного адреса.

    HR slot N = IDA offset (0x4C + N * 4)

Главные слоты:

  HR slot +7    Main AI dispatch (AI_DailyDecision)
  HR slot +8    AI continuation (у TWarrior = WeaponTargeting)
  HR slot +18   Trade dialog hook
  HR slot +24   Stock-up hook
  HR slot +25   Restock equip / CanLandOnPlanet
  HR slot +27   PickEngageTarget (CombatTarget picker via ChanceToWin)
  HR slot +28   PostEngageOrder
  HR slot +30   AdjustRelation
  HR slot +32   engage sub-process
  HR slot +33   ShouldFlee_ChanceBased (у TPirate)
  HR slot +39   Land/Move dispatch
  HR slot +40   Pre-decision tick
  HR slot +44   TryAcceptMoneyRansom
  HR slot +120  Apply reputation delta (OnCombatHit / TWarrior post-accept)
  HR slot +156  Task swap / panic mode toggle
  HR slot +196  TakeOff order

4. AI ПО КЛАССАМ
================================================================================

----- TRanger (0x751B00) -----
3 ветки: planet/station/space. На планете - trade+mission+jump. На станции -
specific dialogs (RC=6, WB=8). В системе - PickBestTradePlanet (торговый scoring),
PickTargetStar_AvoidBlazer (выбор звезды).

Engage: TRanger_AI_PickEngageTarget (0x759EAC, VMT+27) - ChanceToWin > 0.5,
не атакует rangers/police.

----- TPirate (0x5AC1CC) -----
v39 = (ClassStatus[1] > 0) && (Owner == 7): настоящий пират
v39 = false: пирато-воин (через TPlanet_BuyWarrior на пиратской планете)

Кланская координация: 3+ пиратов без миссии -> сбор на CB.
Уникально: TPirate_AI_AmbushTick (засада на планете).

Пираты "хотящие ограбить" реализуют грабёж через:
  1. Атака (PickEngageTarget)
  2. Если жертва выкидывает товары (TryDropGoodsAsRansom) - пират подбирает
     их физически через CargoHook AI и прекращает преследование
  3. Альтернатива: пират при низком HP сам пытается откупиться (TryMoneyRansom)

Engage: TPirate_AI_PickEngageTarget (0x5B0550, VMT+27) - 2 режима (InAggro/обычный)

----- TWarrior (0x5B6ED0) -----
3 AI-функции:
  1. TWarrior_AI_DailyDecision (главный диспетчер VMT+7)
  2. TWarrior_WeaponTargeting (VMT+8) - 7-уровневая weapon assignment
  3. TWarrior_AI_FullCycle (0x5BBFF4) - ТОЛЬКО для BigWarrior (Rating==1)

BigWarrior получает money = clamp(Galaxy._064/15, 1000..5000) каждый день.

----- TTransport (0x5C0550) -----
SubType: 0=Cargo, 1=Liner, 2=Diplomat, 3=Ranger
Liner (Rating=1): +money за visit
Diplomat (Rating=2): +money * (SkillCharm+1)/2 за visit

Engage: TTransport_AI_PickEngageTarget (0x5C2D40, VMT+27).
КРИТИЧНО: TTransport атакует ТОЛЬКО Klings (CurStanding=0 или 9).

----- TTranclucator (0x5CE6FC) -----
AI-компаньон Player'а через ReturnAsArtefact serialization.
Управляется диалогами Talk_Tranclucator_*.

----- TKling -----
См. раздел 6.

----- TRuins (0x6CC6C0) -----
8 типов станций. CB (type=12) - мобильная пиратская база с migration AI.

5. БОЕВАЯ МОДЕЛЬ (ЕДИНАЯ для всех NPC)

----- TShip.ChanceToWin (0x70B380) - ЯДРО -----

  myDmg = sum(WeaponMaxDamage(w) * target.Protectability - target.HullDef
              for w in self.weapons if w.speed>0; only positive)
  targetDmg = аналогично для target.weapons
  if myDmg == 0: return 0.0     # не могу пробить
  if targetDmg == 0: return 100.0  # target не может ответить
  return (self.hp * myDmg / target.hull.size) / (target.hp * targetDmg / self.hull.size)

Интерпретация: >1 побеждаю / <1 проигрываю / 0 бесполезно / 100 instant win.

----- TShip.GetAttitude (0x72F360) -----
Возвращает 0..100. Default = 0 (низкий).

----- TShip.GetRelationToPlayer (0x70BE0C) - 5 уровней -----
  0-9: hostile / 10-29: unfriendly / 30-59: neutral / 60-79: friendly / 80-99: ally

----- TShip_OnCombatHit_ApplyRelationPenalty (0x6CFF7C) -----
При попадании оружия:
  victim.CombatTarget := attacker
  attacker.VMT+120(-10)        # reputation
  star planets relation -= 10 (decentralized call-for-help)

--------------------------------------------------------------------------------
ВЫКУП: ДВА МЕХАНИЗМА
--------------------------------------------------------------------------------

Концепция:
  - Пират хочет ОГРАБИТЬ. Если жертва выкидывает товары - пират подбирает.
  - От пирата можно откупиться (товарами или деньгами).
  - От воина откупиться можно ТОЛЬКО ДЕНЬГАМИ (большой суммой).
  - От Klings откупиться НЕЛЬЗЯ ни товарами, ни деньгами.

A) ТОВАРНЫЙ ВЫКУП: TryDropGoodsAsRansom (0x717CF8)
   Сброс goods в космос. Атакующий пират подбирает через свой CargoHook AI.
   Guard: _1176 RansomGiven flag.
   3 итерации × до 2 типов. Корабль без товаров не откупится.

B) ДЕНЕЖНЫЙ ВЫКУП: VMT+44 = TryAcceptMoneyRansom

   Триггер: TPirate_AI_TryMoneyRansom (0x5AF2E4) - пират решает дать взятку
   при low HP / chase / dist<3 / Money>100.

   Сумма offer: чем ниже HP - тем больше денег.

   target.VMT+44(self, amount) у разных классов:
     TRanger/TPirate/TTransport: принимают по ChanceToWin/ShouldFlee/HP%/amount
     TWarrior: только большая сумма (PathTotal-based, без fear-логики)
     TKling: всегда return 0
     TTranclucator: Talk_NotSupporting_3
     TRuins: sub_6D03E4

--------------------------------------------------------------------------------
ЭФФЕКТЫ ПРИНЯТИЯ ВЫКУПА (post-accept hooks)
--------------------------------------------------------------------------------

Общий хук sub_70C1E0 (все accept):
  - CombatTarget обоих := 0
  - payer._3F8 := target (temporary escort)
  - weapon.target clear
  - Если payer=Ranger: target.VMT+30(+10) (relation)
  - Если target=Ranger: payer.VMT+30(+30)
  - Recursive cleanup для всех ships с _1020 == payer/target

Класс-специфические:
  TWarrior (sub_5BCE84):
    Money transfer. ДЛЯ ВСЕХ Warriors с HomePlanet == self.HomePlanet:
      Очищает CombatTarget == payer, weapon.target
      Warrior.VMT+120(+30, payer)  ## +30 К РОДНОЙ ПЛАНЕТЕ ВОИНА
    ВЗЯТКА ВОИНУ = ВЗЯТКА ВСЕЙ РОДНОЙ ПЛАНЕТЕ.

  TPirate (sub_5B20F4):
    Money transfer. Если payer=Ranger:
      Planet_PirateClan.relation_to_ranger += 10
    Если pirate-pirate в pirate system: вся пиратская команда clear CombatTarget.

  TRanger (sub_75B6B8): money transfer + special star.Owner==7 handling.
  TTransport (sub_5C3D8C): простой money transfer + sub_70C1E0.

----- Системный flee: TNormalShip.AI.FleeIfOutgunned (0x5B3904) -----
Через TStar_CalcPowerByStanding (cached per-day):
  threshold = |coalition - 2.5*dominator| * v33
  if threshold >= pirate_power OR AllWeaponsDisabled: flee

7. ПАРТНЁРСТВО И НАЁМ КОМАНДЫ

Игровая концепция:
  - Рейнджеры могут нанимать ДРУГИХ РЕЙНДЖЕРОВ в партнёры. AI-рейнджер может
    нанять Player'а, Player может нанять AI-рейнджера.

    ПИРАТОВ через Construct Base (CB) пиратских систем.
  - Партнёры подчиняются командам владельца, получают деньги, могут отдавать
    cargo, выполнять Order'ы.

Найм рейнджера: Talk_Partner_AskJoin (0x61067C)
--------------------------------------------------------------------------------

Когда Player разговаривает с рейнджером и предлагает партнёрство:

ПРОВЕРКИ (по порядку):
  1. GetAttitude(target, Player) >= 45 (0x2D)
     Иначе: 'Talk.Partner.Suspect' ("я вам не доверяю")
  2. target.FShipPartner == nil
     Иначе: 'AlreadyHavePartner' ("я уже в команде")
  3. target.Skill_Leadership <= 0 (через sub_753514)
     Иначе: 'ILeader' ("я сам командую, не подчиняюсь")
  4. Player.Skill_Leadership > target.Leadership
     Иначе: 'NeedLeadership' ("у вас недостаточно лидерства")
  5. target.Rank <= Player.Rank
     Иначе: 'YouNeedInMoreRank' ("у вас низкий ранг")

РАСЧЁТ ЦЕНЫ:
  initial_offer := dword_889C40 (глобал)
  target.VMT+188(Player, offer) - предварительная проверка приемлемости

ВАРИАНТЫ ИГРОКА:
  - 'PlayerOk' - согласиться -> sub_610E40 -> SE_ShipSetPartner(ranger, Player, day)
  - 'PlayerLess' (если offer/2 > 0) - предложить меньше -> Talk_Partner_AskJoin_Callback
  - 'PlayerMore' (если Money > offer) - предложить больше -> sub_610EE0
  - 'Cancel'

     - dword_889B6C[2*1..5]   (5 слотов artefacts/special)

  5. TPirate_InitShip(newPirate, star_id, initial_money, 0)
  6. newPirate.CurRuins := Player.CurRuins
  7. newPirate.VMT+120(+100, Player) - макс reputation

       newPirate.FShipPartner (+0x3FC) := Player
       newPirate.FShipPartnerDay (+0x400) := 30 * payment_factor
