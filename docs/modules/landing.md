# Посадка

Код: `Utils/PlanetGeometry.cs`, `NpcAI/Orders/OrderLand.cs`, `Ships/Player/PlayerShip.Route.cs`,
`Presentation/World/ShipVisualController.cs`.

## Геометрия

- `R_vis` — визуальный радиус планеты (`BaseScale / 2` из графического конфига).
- `R_land = R_vis + LandingZoneMargin` — конец хода внутри этого радиуса означает посадку.
- `R_app = R_vis + ApproachZoneMargin` — зона подхода.

Позиция планеты к моменту подлёта считается итеративно (`OrbitMath.PredictPlanetCatchUpPosition`).

## Точка прицеливания

**Игрок.** Внутри `R_app` — прямо в упреждённый центр планеты. Снаружи — в точку
посадочного кольца на стороне корабля (глубина `0.6 · R_land`), чтобы корабль входил
в кольцо, а не пролетал диск насквозь.

**НПС.** Вокруг планеты 8 посадочных коридоров. Корабль берёт коридор, ближайший к своему
пеленгу, со сдвигом на соседний по хешу пары «корабль–планета», и садится на свою глубину
`0.45..0.8 · R_land`. Несколько НПС с одной стороны расходятся по коридорам, а цель стабильна
между ходами.

## Двухфазный цикл

1. **Подлёт.** `PrepareForTurn` смотрит конец траектории хода: если он внутри `R_land` цели,
   ставится `LandingPhase = Fading`.
2. **Финализация.** На следующем шаге логики (`OrderLand` / `PlayerShip.TryFinalizeLanding`)
   корабль считается севшим. Вне системы игрока проверка идёт напрямую по дистанции.

## Визуал

Первую четверть финального хода корабль виден полностью, затем растворяется по smoothstep.
Взлёт — зеркально. Константа — `ShipVisualController.LandingFadeHold`.
