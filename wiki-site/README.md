# Вики New SRG

[Открыть вики-сайт](https://newsrg-wiki.franksorbet.chatgpt.site) · Доступ владельцу через ChatGPT.

Статическая энциклопедия по текущим досье и справочникам из `GameDoc`: 19 статей о расах и 9 общих справочников. Главная страница, полнотекстовый поиск, оглавления, ссылки между статьями, светлая и тёмная темы, адаптивная навигация. Телефонная версия использует выдвижное меню, встроенное оглавление и горизонтальную прокрутку широких таблиц. Оформление — в духе классической игровой вики с синими панелями и космическим фоном; точное визуальное совпадение с указанным Fandom-образцом не проверено из-за ограничения доступа к нему.

Физиология, параметры миров и технические разделы свёрнуты в раскрывающиеся блоки. Переход по ссылке на скрытый подраздел раскрывает его. В расовые досье добавлены восприятие событий и ссылки на объективную статью периода; субъективные оценки не объявляются объективной истиной.

## Сборка

Из корня репозитория:

```bash
cd wiki-site
node build.mjs
```

Результат находится в `wiki-site/dist/` и может размещаться на статическом хостинге. В репозитории исходниками служат соседние `GameDoc/race_*.md` и `GameDoc/reference_*.md`. В автономном исходном проекте хостинга используется каталог `content/` с теми же текстами. При обновлении сайта этот снимок нужно обновлять из принятой редакции досье, затем пересобирать.

Сборщик использует включённый Marked с сохранённой лицензией. Не требует установки пакетов. Внутренние адреса разделов сохраняются; ссылки на документы вне опубликованного набора ведут на GitHub.

GitHub-пробы двух статей: [Синапты](../GameDoc/wiki/sinapty.md), [Ксеноподы](../GameDoc/wiki/ksenopody.md).
