# Вики New SRG на GitHub Pages

Стартовая страница: [index.html](../index.html). Статьи и ресурсы: [wiki/](../wiki/).

Сайт полностью статический: 19 расовых статей, 9 справочников, поиск, ссылки, спойлеры с технической информацией и телефонная версия. Хостинг ChatGPT Sites больше не используется в качестве адреса проекта.

## Публикация

В настройках репозитория откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow **Publish New SRG wiki** собирает только сайт и публикует его через GitHub Pages. После первого включения запустите workflow через Actions → Publish New SRG wiki → Run workflow, если автоматический запуск уже завершился ошибкой из-за выключенных Pages.

Ожидаемый адрес после успешной публикации: https://cheniska.github.io/New_SRG/

## Пересборка HTML

Из корня репозитория:

```bash
cd wiki-site
node export-github.mjs
```

Команда пересобирает корневой index.html и папку wiki/ из актуальных Markdown-статей GameDoc. Workflow делает это автоматически при изменении документов. Исходные досье остаются источником канона; в расовые статьи из общей истории добавлены их точки зрения и ссылки на объективное изложение.

Для независимого каталога публикации:

```bash
node export-github.mjs ../.pages
```

В папку публикации попадают только index.html, .nojekyll и wiki/; файлы Unity-проекта не публикуются. Сборщик использует включённый Marked с сохранённой лицензией и не требует установки пакетов.
